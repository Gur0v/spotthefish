# Spot the Fish

[English version](./README.md)

Десктопна українська вебгра для навчання розпізнаванню фішингу.

Побудована на Next.js, React, TypeScript, Tailwind CSS, статичних JSON-даних уроків і прогресі через `localStorage`.

Без email-акаунтів. Без паролів. Без платежів. Без таблиць лідерів. Без збору персональних даних.

За замовчуванням сайт повністю працює локально через `localStorage`. Опційно можна увімкнути Supabase-синхронізацію через 16-значний код доступу.

## Що це

Spot the Fish навчає розпізнавати онлайн-шахрайство через короткі інтерактивні уроки.

Основна аудиторія — нетехнічні українські користувачі, особливо дорослі та мами.

Маскот проєкту — **Фішко**, синя рибка-детектив.

## Прогрес

Прогрес за замовчуванням зберігається в `localStorage`.

Зберігаються:

- завершені уроки
- відкриті уроки
- результати
- зірки
- серія проходжень
- розмір тексту
- налаштування звуку
- мова

Завершення уроку відкриває наступний.  
Повторне проходження може покращити збережений результат.

У налаштуваннях є підтвердження скидання прогресу.

Також є прихована пасхалка: 20 натискань на `Українська` відкривають усі уроки.

Опційна синхронізація використовує 16-значний цифровий код. Вона не використовує Supabase Auth, email, імена користувачів або паролі. Supabase використовується тільки як Postgres-сховище через серверні route handlers.

Для синхронізації потрібні змінні середовища:

```text
NEXT_PUBLIC_SUPABASE_URL=
SUPABASE_SERVICE_ROLE_KEY=
ACCOUNT_LOOKUP_SECRET=
SESSION_PASSWORD=
```

Вони потрібні тільки для синхронізації. Гра працює без них у локальному режимі. Ніколи не комітьте `.env.local` або справжні секрети.

## Локальний запуск

```bash
bun install
bun run dev
````

Відкрити:

```text
http://localhost:3000
```

## Production build

```bash
bun run build
bunx next start -H 0.0.0.0 -p 3000
```

## Локальна мережа

Щоб відкрити сайт у локальній мережі:

```bash
bunx next start -H 0.0.0.0 -p 3000
```

Знайти LAN IP:

```bash
ip a
```

Потім відкрити з іншого пристрою в тій самій мережі:

```text
http://YOUR_LOCAL_IP:3000
```

## Структура проєкту

```text
app/          маршрути Next.js
assets/       зображення, маскоти, іконки
components/   UI-компоненти
data/         дані уроків і питань
lib/          допоміжна логіка
scripts/      службові скрипти
```

## Примітка щодо розробки

Проєкт розроблявся з використанням агентних інструментів для написання коду. Очікуйте баги, нерівні краї та місцями сумнівні рішення. Перевіряйте зміни перед тим, як їм довіряти.

## Приватність

Email/password акаунтів немає.

Прогрес зберігається в браузері через `localStorage`. Очищення даних браузера або сайту видалить прогрес.

Якщо опційну синхронізацію налаштовано, прогрес також можна зберігати в Supabase під випадковим 16-значним кодом. Сирі коди доступу не зберігаються.
