# Spot the Fish

[English version](./README.md)

Spot the Fish — desktop-first українська вебгра для навчання розпізнаванню фішингу, яка також працює на телефонах. Вона допомагає помічати онлайн-шахрайство через короткі дружні уроки з практичними прикладами.

Маскот проєкту — **Фішко**, синя рибка-детектив.

## Основне

- 16 уроків у 4 модулях
- 238 питань українською
- Desktop-first адаптивний інтерфейс
- Локальний прогрес через `localStorage`
- Опційна приватна синхронізація через код доступу
- Без email, імен користувачів, паролів, платежів, профілів і таблиць лідерів

## Уроки

Модулі:

| # | Модуль |
|---|--------|
| 1 | Підозрілі повідомлення |
| 2 | Посилання і сайти |
| 3 | Популярні сервіси |
| 4 | Безпечні дії |

Теми: фейкова підтримка, SMS-коди, підозрілі посилання, фейкові сайти, QR-платіжні пастки, шахрайство на OLX, у Telegram, Viber, з доставкою, банківські пастки, прохання про гроші від "родичів" і безпечна перевірка інформації.

## Ігровий процес

Типи завдань:

- натиснути на підозрілу частину повідомлення
- вибрати справжнє або фейкове повідомлення
- обрати найбезпечнішу дію
- визначити безпечне або підозріле посилання

Завершення уроку відкриває наступний. Повторне проходження може покращити збережений результат.

## Прогрес І Приватність

За замовчуванням прогрес зберігається тільки в браузері через `localStorage`.

Опційна синхронізація використовує 16-значний цифровий код доступу. Вона не використовує Supabase Auth, email, імена користувачів або паролі. Supabase використовується тільки як Postgres-сховище через серверні route handlers.

У синхронізацію потрапляють тільки прогрес і налаштування:

- завершені та відкриті уроки
- результати, зірки та серія
- мова, розмір тексту і звук

Самі коди доступу не зберігаються. У базі зберігаються HMAC-хеш для пошуку і секретний хеш для перевірки.

## Технології

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Bun
- статичні JSON-дані уроків
- опційна синхронізація через Supabase Postgres

## Змінні Середовища

Гра працює без Supabase-змінних у режимі тільки з `localStorage`.

Для синхронізації через код доступу потрібні:

```text
NEXT_PUBLIC_SUPABASE_URL=
SUPABASE_SERVICE_ROLE_KEY=
ACCOUNT_LOOKUP_SECRET=
SESSION_PASSWORD=
```

Ніколи не комітьте `.env.local` або справжні секрети.

## Локальний Запуск

```bash
bun install
bun run dev
```

Потім відкрийте `http://localhost:3000`.

## Build

```bash
bun run build
bunx next start -H 0.0.0.0 -p 3000
```

## Smoke-Тест Коду Доступу

Запустіть проти вже піднятого сервера з налаштованими змінними для синхронізації:

```bash
bun run smoke:access http://localhost:3000
```

Тест перевіряє створення коду, сесію, збереження прогресу, завантаження прогресу, вихід, повторний вхід, повторне завантаження прогресу і видалення коду доступу.

## Локальна Мережа

```bash
bunx next start -H 0.0.0.0 -p 3000
ip a
```

Потім відкрийте `http://YOUR_LOCAL_IP:3000` з іншого пристрою в тій самій мережі.
